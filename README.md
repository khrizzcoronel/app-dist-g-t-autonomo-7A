## Objetivo

Centralizar de forma organizada los trabajos autónomos, documentos y referencias utilizadas por el grupo durante la asignatura de Aplicaciones Distribuidas.

## Estructura del repositorio

```text
trabajos-autonomos-aplicaciones-distribuidas/
├── referencias/
├── GA-TL-01/
└── README.md
```

La carpeta `referencias/` contiene las fuentes bibliográficas utilizadas durante el desarrollo de los trabajos.

Cada actividad tendrá su propia carpeta identificada mediante el código asignado por la asignatura. Dentro de cada una se almacenarán los documentos, archivos fuente y demás entregables solicitados.

Conforme avance la asignatura, se agregarán nuevas carpetas siguiendo la misma organización:

```text
trabajos-autonomos-aplicaciones-distribuidas/
├── referencias/
├── GA-TL-01/
├── GA-TL-02/
├── GA-TL-03/
└── README.md
```

## Referencias bibliográficas

Las referencias utilizadas por el grupo se mantendrán centralizadas en la carpeta:

```text
/referencias/
```

Cuando corresponda, las citas y referencias bibliográficas se presentarán siguiendo el formato **IEEE**.
